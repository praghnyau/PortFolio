# U.Praghnya — Portfolio

Personal site for U.Praghnya: a quiet journey through learning, building, and what's next.

## Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion.

## Edit content

Update files in `src/data/` (`site.ts`, `projects.ts`, `journey.ts`, `skills.ts`) without touching layout.

Replace the LinkedIn URL in `src/data/site.ts` if the placeholder is wrong.

## Scripts

```bash
npm install
npm run dev
npm run build
```
